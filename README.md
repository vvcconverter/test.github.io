# FastSite — миниатюра

Статический демонстрационный сайт на чистом HTML, CSS и JavaScript.

## Возможности
- адаптивный тёмный интерфейс;
- две страницы для проверки переходов;
- предзагрузка same-origin ссылок при появлении на экране и наведении, если браузер поддерживает requestIdleCallback;
- Service Worker: кеш статики, network-first для HTML, fallback на кеш при офлайне;
- лаборатория с отображением состояния кеша, сети и Navigation Timing;
- не требует сборки или сторонних библиотек.

## Запуск локально
Service Worker работает только на HTTPS или localhost. Из папки проекта запусти:

```bash
python -m http.server 8080
```

Открой http://localhost:8080.

## Публикация на GitHub Pages
1. Создай репозиторий.
2. Загрузи содержимое этой папки в корень репозитория.
3. В Settings → Pages выбери публикацию из ветки `main`, папка `/ (root)`.
4. Открой опубликованный адрес по HTTPS.

Относительные пути рассчитаны в том числе на публикацию в подпапке репозитория.

## Важные ограничения
- Это демонстрационный прототип, не обещание мгновенной загрузки.
- Предзагрузка зависит от браузера и его настроек, может не запускаться при экономии трафика.
- Service Worker требует HTTPS или localhost.
- Для production добавь иконки PWA, тестирование обновлений, CSP, доступность и версионирование ассетов.
- Brotli обычно лучше включать на сервере/CDN через Content-Encoding: br; для обычного сайта не нужно скачивать пакет и распаковывать его вручную.
- Speculation Rules API и prerender отдельно тестируй на контролируемой странице, не на страницах оплаты/личных данных.
